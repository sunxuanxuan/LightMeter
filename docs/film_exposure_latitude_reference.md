# 主流胶片曝光宽容度参考表

## 1. 使用口径

本文统一以**中央重点测光结果作为 18% 灰，即 0 EV 基线**：

- **+EV**：比测光值增加曝光，进入过曝方向。
- **-EV**：比测光值减少曝光，进入欠曝方向。
- “建议实用范围”偏向日常可控结果；“极限可用参考”表示在扫描、后期或冲扫条件较好时可能仍可获得可用画面，但不建议作为常规曝光策略。

彩色负片通常比反转片更能承受过曝，消费级 Kodak Gold 200 官方技术资料标注其宽容度为**欠曝 2 档到过曝 3 档**[[KODAK GOLD 200 Film](https://kodakprofessional.com/sites/default/files/wysiwyg/pro/resources/E7022%20Gold%20tech%20sheet.pdf)。Kodak Vision3 50D 5203 的资料说明，“0”代表 18% 灰正常曝光，白卡位于正常曝光以上 2⅓ stops，且其上至少还有 3½ stops 可记录镜面高光；3% 黑卡位于正常曝光以下 2⅔ stops，且其下至少还有 2½ stops 可记录阴影细节[[KODAK VISION3 Films deliver premium image](https://www.kodak.com/content/products-brochures/Film/VISION-50D-Sellsheet_US-180929-SP_EN.pdf)。Kodak Ektachrome 100 属于日光型彩色反转片，技术资料建议关键拍摄应做分档测试，反转片实际使用中应优先保护高光[[KODAK EKTACHROME 100 Professional Film](https://www.cameramanuals.org/kodak_pdf/kodak_ektachrome_100.pdf)。

## 3. 分组说明

### 3.1 Kodak 200 / 400 消费级彩色负片

Kodak Gold 200 是最适合作为消费级彩负基准的参考对象，其官方资料明确写出宽容度为**欠曝 2 档到过曝 3 档**[[KODAK GOLD 200 Film](https://kodakprofessional.com/sites/default/files/wysiwyg/pro/resources/E7022%20Gold%20tech%20sheet.pdf)。因此在中央重点测光准确时，Gold 200 可按 **-2 EV / +3 EV** 作为保守实用框架。UltraMax 400 虽然未在本表中直接引用到同等明确的官方宽容度句子，但作为同类 C-41 消费彩负，可按接近 Gold 200 的思路使用；由于 ISO 更高，暗光场景下比 Gold 200 更稳，但仍应避免欠曝。

### 3.2 Fujifilm 200 / 400 彩色负片

现行 Fujifilm 200 / 400 在实际市场中常被按 Kodak Gold 200 / UltraMax 400 的使用逻辑处理，实拍建议上可沿用**消费级彩负：避免欠曝、允许适度过曝**的原则。旧日版 Fujifilm C200 / Superia X-TRA 400 的色彩和批次差异更明显，若追求稳定扫描结果，建议不要长期使用极限欠曝。

### 3.3 Lucky / 乐凯 C200 / 400 彩色负片

乐凯 C200 的第三方评测普遍认为其宽容度不如 Kodak Gold 200 / Portra 等成熟负片，暗部更容易变脏，高光也更快进入不可控状态；The Darkroom 的评测也指出 Lucky 200 相比 Gold 200 或 Portra 160 曝光宽容度更有限，适合更仔细测光[[Lucky Color 200 Film Reviews & Photos - The Darkroom Photo Lab](https://thedarkroom.com/film/lucky-color-200/)。因此建议把 C200 的日常范围收窄到约 **-1 ~ -1.5 EV / +1.5 ~ +2.5 EV**。乐凯 400 公开可靠资料不足，建议先按新彩负的保守估算使用，并通过同场景包围曝光确认。

### 3.4 Kodak Vision3 5207 / 5203 电影彩色负片

Vision3 系列相较普通消费彩负有更强的高光保留能力。Kodak 对 Vision3 50D 5203 的资料明确把 18% 灰正常曝光设为曲线 “0” 点，并说明白卡以上仍有至少 3½ stops 用于镜面高光，黑卡以下仍有至少 2½ stops 用于阴影细节[[KODAK VISION3 Films deliver premium image](https://www.kodak.com/content/products-brochures/Film/VISION-50D-Sellsheet_US-180929-SP_EN.pdf)。因此 5203 可以给出比普通彩负更高的上限参考：日常实用约 **-3 EV / +4 ~ +5 EV**。5207 / 250D 同属 Vision3 家族，Kodak 页面强调其高光宽容度和后期灵活性[[VISION3 250D Color Negative Film 5207/7207 | Kodak](https://www.kodak.com/en/motion/product/camera-films/250d-5207-7207/)，可按 **-3 EV / +3.5 ~ +4.5 EV** 保守使用。

### 3.5 Kodak E100 / 5294 反转片

E100 与 5294 / 7294 这类 Ektachrome 反转片的核心策略是**保护高光**。反转片没有彩色负片那种大幅过曝后的扫描修复空间，高光一旦透明片密度不足或颜色失真，后期很难救回。以中央重点测光准确为 0 EV 时，建议把日常安全上限控制在 **+0.5 ~ +0.7 EV**，下限约 **-1 ~ -1.5 EV**。如果画面中有重要高光，建议宁可 0 EV 或 -0.3 EV，也不要为了提亮阴影而让高光越过上限。

## 4. 实拍建议

1. **彩色负片**：优先避免欠曝。日常可以给 **+0.3 ~ +1 EV**，尤其是人像、阴天、逆光、室内窗光等场景。
2. **消费级彩负**：不要迷信“负片随便过曝”。+2 EV 通常仍可用，+3 EV 已经很依赖冲扫和扫描；如果高光面积大，建议收敛到 +1 ~ +2 EV。
3. **Vision3 电影卷**：比普通消费彩负更适合高反差场景，尤其是 5203 / 50D 的日光高光表现很强；但若使用 C-41 跨冲而非 ECN-2，结果可能与官方资料存在差异。
4. **反转片**：把高光当作第一优先级。中央重点测光准确时，可从 0 EV 开始；高反差或强日光场景可考虑 **-0.3 EV**。
5. **点测高光**：点测会把被测高光当作 18% 灰。如果测的是“希望保留细节的高光”，通常应把它放在约 **+1.3 ~ +1.7 EV**，而不是在点测值基础上再 -0.5 EV。
6. **不确定批次或冲扫条件时**：建议做 **-1 / 0 / +1 EV** 的包围曝光；反转片可做 **-0.7 / -0.3 / 0 / +0.3 EV** 的细分包围。

## 5. 快速结论

- **最稳妥彩负策略**：按测光值正常曝光或 +0.3 ~ +1 EV。
- **消费彩负实用框架**：约 **-2 EV / +3 EV**。
- **Vision3 实用框架**：约 **-3 EV / +4 EV 以上**，5203 高光尤其强。
- **E100 / 5294 反转片实用框架**：约 **-1 ~ -1.5 EV / +0.5 ~ +0.7 EV**。
- **反转片拍摄原则**：宁可轻微欠曝保护高光，不要明显过曝。
