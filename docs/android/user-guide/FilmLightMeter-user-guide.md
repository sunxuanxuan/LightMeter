# FilmLightMeter 胶片模拟使用说明书

FilmLightMeter 帮助你在按下真实相机快门前，先查看不同一次性相机和胶片组合下，
画面大致会呈现的效果，并根据现场光线给出简单建议。

你不需要了解摄影参数。只要选择准备使用的机型和底片，对准想拍的画面，再查看
模拟结果和提示即可。

## 开始使用

1. 打开 App，首次使用时允许访问相机。
2. 在首页点击 **胶片模拟**。
3. 将手机对准准备拍摄的场景，保持画面稳定。
4. 先选择机型和底片，再查看画面下方的建议。

> 请让手机朝向你要拍摄的场景。建议先擦净手机镜头，并避免强烈反光直接照入镜头。

## 选择机型

点击底部左侧的 **机型** 图标，底部会弹出可选机型。

1. 左右滑动浏览。
2. 点击你准备使用的相机。
3. 选中后会自动回到取景画面。

应用会记住上一次选择，下次进入时会自动恢复。部分一次性相机使用固定底片；
这类机型仍可查看底片信息，但不需要另外选择。

如果你使用的不是列表中的机型，可在机型列表中选择 **自定义**，再按自己的实际
设备进行设置。

## 选择底片

点击底部右侧的 **底片** 图标，选择准备装入相机的底片。

1. 左右滑动浏览可用底片。
2. 点击一卷底片完成选择。
3. 回到取景画面后，模拟结果和建议会随之更新。

只有支持更换底片的机型可以切换。若当前机型使用固定底片，应用会保留其对应的
选择，避免得到不符合实际使用方式的结果。

## 查看拍摄建议

取景画面下方会持续显示当前场景的建议。等待几秒，让提示稳定后再判断。

| 标记 | 含义 | 建议 |
| --- | --- | --- |
| ✅ 绿色 | 画面亮度合适 | 可以正常拍摄。 |
| ！ 橙色 | 画面可能偏暗或偏亮 | 偏暗时到光线更充足的位置；偏亮时到光线稍暗的位置。 |
| ❌ 红色 | 画面过暗或过亮，成片失败风险较高 | 画面过暗时开启闪光灯或靠近主体；画面过亮时移到阴影处拍摄。 |

建议是针对当前选择的机型和底片给出的。切换机型、底片或改变取景方向后，请重新
观察提示。

## 查看成片模拟

中间的红白圆形按钮用于冻结当前画面并生成模拟结果。

1. 对准场景，确认底部建议已稳定。
2. 点击中间拍摄按钮。
3. 保持手机稳定，等待画面生成。
4. 生成完成后，画面会显示手机原始画面与胶片模拟画面的对比。

刚点击按钮时，会先显示“正在根据当前机型和底片生成成片模拟”。这属于正常等待。
请勿连续点击按钮或立即移动手机。

## 对比原画面和模拟画面

模拟完成后，画面中央会出现一条竖向分割线。

- 向左或向右拖动分割线，可查看更多原始画面或更多模拟画面。
- 将分割线拖到不同位置，重点比较人物脸部、天空、窗边和阴影中的细节。
- 如果模拟画面明显过暗、过亮，或关键主体不清楚，请先按页面建议调整位置或光线，
  然后重新冻结查看。

模拟完成后，底部第一行会切换为“返回”和“下载”：

- 点击“返回”退出对比并恢复实时取景。
- 点击“下载”将右侧的完整胶片模拟成片保存到系统相册，然后自动恢复实时取景。

Android 8 或 Android 9 首次下载时需要授予存储权限。Android 10 及以上版本不需要
额外的照片读取权限。照片保存在系统图片目录的 `FilmLightMeter` 相册中。

## 推荐拍摄流程

1. 在真实相机上确认准备使用的机型和底片。
2. 在 App 中选择相同的机型和底片。
3. 对准场景，查看绿色、橙色或红色建议。
4. 若提示橙色或红色，先移动到更合适的位置，或按提示使用闪光灯。
5. 点击中间按钮，查看模拟画面。
6. 拖动分割线，对比原画面和模拟画面中的主体与亮暗细节。
7. 确认效果后，用真实相机拍摄。

## 使用提示

- 闪光灯建议适合拍摄距离较近的人物或物体。主体太远时，开启闪光灯也可能没有明显效果。
- 逆光、窗边、舞台灯、夜景和大面积白色背景等场景变化较大，建议多换一个取景位置再比较。
- 手机画面和真实胶片会受到不同镜头、冲洗和扫描方式影响。模拟用于辅助决定是否拍摄，
  不能保证与最终成片完全一致。
- 极暗环境中，建议优先使用闪光灯，或选择有更充足光线的位置。

## 常见问题

### 为什么拍摄按钮暂时不能点击？

应用正在连接相机、等待画面稳定，或你刚从后台回到应用。请稍等几秒，让实时画面和
底部提示恢复后再试。

### 为什么点击后没有立刻显示模拟图？

应用需要保存当前画面并生成模拟效果。请保持手机稳定，等待提示从“正在生成”变为
正常建议。若长时间没有变化，点击返回箭头恢复取景后再试一次。

### 为什么切换底片后不能选择？

当前一次性相机使用固定底片，无法更换。选择支持换卷的机型后，底片列表会允许切换。

### 为什么模拟结果和真实照片可能不同？

手机相机和真实胶片相机看到的画面、镜头和处理方式并不完全相同。模拟结果用于帮助你
判断当前光线是否适合拍摄，以及是否需要调整位置或开启闪光灯。
