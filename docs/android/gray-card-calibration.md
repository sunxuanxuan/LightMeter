# Android 灰卡校验

> 当前状态：实验功能已隐藏。算法、采样页面和持久化结构保留，但应用不展示
> 首次启动提示、模式选择入口或其他用户入口。

## 目标

不同 Android 设备的 ISO 标定、Camera ISP、自动曝光目标和 YUV 输出可能造成近似
固定的 EV 偏差。灰卡校验计算一个设备级 `calibrationOffset`，统一修正：

- 专业模式整体测光和曝光组合；
- 一次性相机预览模式整体 EV 与固定曝光差值；
- 同帧 ExposureMap、宽容度预警和胶片曝光模拟。

## 校验基准

灰卡本身不能提供绝对场景 EV。准确校验需要：

1. 均匀照亮的 18% 灰卡；
2. 专业测光表或已校准相机提供的参考 `EV100`；
3. 参考设备设置为 ISO 100、曝光补偿 0。

校验页面始终以 `calibrationOffset = 0` 采集原始结果，避免旧偏移参与新校验：

```text
calibrationOffset = referenceEV100 - median(rawMeasuredEV100)
```

## 稳定性约束

- 前 5 个结果只用于等待 AE 稳定；
- 随后采集 12 个有效结果；
- 使用中位数抵抗偶发离群值；
- 10% 到 90% 分位跨度不得超过 0.35 EV；
- 最终偏移限制在 `[-3 EV, +3 EV]`。

不满足约束时不写入设置，用户必须调整照明、构图或参考 EV 后重试。

## 预留的首次启动与持久化方案

重新开放功能后，计划在首次进入应用时主动显示校验提示，并在模式选择页提供
“灰卡校验”入口。当前版本不执行该引导。

校验结果保存在 `SharedPreferencesAppSettingsStore`。记录同时绑定厂商、型号、
系统 Build Fingerprint 和校验算法版本；设备迁移、系统升级或算法版本变化后，
应用会重新提示校验。

## 当前边界

当前应用绑定默认后置逻辑相机，因此偏移按该相机管线全局保存。部分手机在变焦时
会自动切换物理镜头；如果不同物理镜头的 ISO/ISP 标定差异明显，后续应在
`CameraController` 暴露 Camera ID 和 Active Physical Camera ID，并将偏移扩展为
按镜头保存。
