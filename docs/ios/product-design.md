# FilmLightMeter iOS 产品设计

## 1. 文档状态

- 阶段：实现前设计基线
- 目标平台：iPhone
- 最低系统：iOS 17
- 首发形态：原生 iOS App
- Android 行为参考：当前 `android/app/`

本文定义 iOS 首个可发布版本的功能范围、交互要求和验收标准。技术实现以
[iOS 技术架构](technical-architecture.md)为准。

## 2. 产品目标

FilmLightMeter iOS 面向胶片摄影用户，通过 iPhone 后置相机完成反射式测光，
根据胶片 ISO、曝光补偿和目标相机焦段输出光圈/快门组合，并在冻结画面后提示
高光和暗部细节风险。

首版目标：

1. Android 与 iOS 对同一场景给出可解释、可校准的 EV100。
2. 保持曝光组合、画幅、胶片宽容度和风险颜色的跨平台语义一致。
3. 遵循 iOS 权限、生命周期、辅助功能和隐私规范。
4. 测光与风险图使用同一分析帧，推荐曝光误差不超过 $1/6 EV$。

## 3. 非目标

首版不包含：

- iPad、macOS、watchOS 或 Vision Pro 版本。
- 入射式测光附件支持。
- RAW 拍照、照片库编辑或扫描底片。
- 云端账号、跨设备同步和在线胶片数据库。
- Android/iOS 像素级一致的视觉复刻。
- 对任意胶片、冲洗和扫描流程作结果保证。

## 4. 用户流程

### 4.1 首次启动

```text
启动
  -> 激活校验
  -> 模式选择
  -> 进入专业测光
  -> 相机用途说明
  -> 请求相机权限
  -> 进入实时预览
```

权限拒绝后不重复自动弹出系统授权框。页面解释功能依赖，并提供“打开设置”
按钮。激活信息不得依赖广告标识符、序列号或其他受限设备接口。

### 4.2 实时测光

主页面包含：

- 相机预览和有效取景框。
- 点测光位置或中央重点区域提示。
- 当前 EV100。
- 光圈和快门候选滚轮。
- 当前推荐组合。
- ISO、曝光补偿、画幅和目标焦段入口。
- 冻结按钮和设置入口。

用户改变焦段时，界面保留上一组稳定结果。实际变焦倍率稳定且新 revision
帧到达后，再一次性更新 EV 和推荐组合，禁止中间显示无效占位值。

### 4.3 冻结与风险预览

用户点击冻结后：

1. 固定当前分析帧、曝光元数据和未平滑 EV。
2. 暂停实时结果更新。
3. 从同一帧按需生成曝光图。
4. 绘制红色高光风险和绿色暗部风险。
5. 允许调整曝光补偿并基于原冻结快照重算蒙层和模拟图。
6. 默认显示原图风险视图，允许切换到不叠加风险蒙层的 EC 模拟图。

分析进行中应保留冻结图，不用黑屏或相机预览替换。取消冻结时立即终止分析并
回到实时测光。冻结状态保存设置时保留原冻结帧，并按新参数重新分析。

## 5. 功能范围

### 5.1 测光模式

- 平均测光：统计有效取景框。
- 中央重点：中央面积和权重可调。
- 中央区域平均：只读取画面中央圆形区域，用于具有明确接受角的机型预设。
- 点测光：面积为取景框面积的 `1%` 至 `10%`。
- 点击临时点测光：点击预览后临时覆盖当前预设。
- Olympus 35 SP：提供平均 `20°`（约 `20%` 面积）和点测 `6°`
  （约 `2%` 面积）预设，不修改用户设置的焦段。
- 机型预设按当前测光模式过滤；自定义模式显示可编辑参数，机型预设显示只读
  参数摘要。

白色点测光圈只在用户点击画面进入临时点测光后显示，视觉半径保持为实际 ROI
半径的 $1/4$。所有常驻测光模式和机型预设均不显示测光圈。

### 5.2 曝光设置

- ISO：沿用 Android 的候选集合。
- 曝光补偿：`-3 EV` 至 `+3 EV`，步进 $1/3 EV$。
- 光圈：$1/3$ 档候选。
- 快门：经典整档候选。
- 推荐组合误差：不超过 $1/6 EV$。
- 手动选择光圈或快门后，匹配最接近的另一项。

### 5.3 画幅与焦段

支持：

- 135
- APS-C
- 6x4.5
- 6x6
- 目标焦段 `20 mm` 至 `150 mm`

iOS 使用相机视场角计算目标倍率，不假设系统公开传感器物理尺寸。设备无法
达到理论倍率时，取景框、测光 ROI 和风险统计都必须基于实际可达倍率。

### 5.4 胶片宽容度

胶片预设与公共资料
[胶片曝光宽容度参考](../shared/film-exposure-latitude-reference.md)保持一致。
用户可以关闭风险预览，或按 $1/3 EV$ 调整高光和暗部阈值。

### 5.5 设置持久化

以下设置在重新启动后恢复：

- ISO 和曝光补偿。
- 画幅和目标焦段。
- 测光模式、点测光面积、中央面积及权重。
- 胶片预设、高光/暗部阈值和风险开关。
- 设备校准偏移。

冻结状态、临时点测光位置、实时 EV 和相机错误不持久化。

## 6. iOS 交互适配

### 6.1 导航

激活后进入双模式首页。专业测光页提供返回模式选择入口，进入和离开专业模式时
分别启动、停止相机会话。设置使用 SwiftUI `sheet`，较长内容使用独立滚动，
保存成功后关闭。相机权限、激活和不可恢复错误使用独立状态页。

### 6.2 手势

- 单击预览：临时点测光。
- 上下拖动滚轮：选择 ISO、EC、光圈或快门。
- 水平拖动焦段滑块：调整目标焦段。
- 不使用与系统返回手势冲突的屏幕边缘手势。

### 6.3 方向

首版只支持竖屏。相机输出、冻结图、点击坐标和风险蒙层统一使用竖屏显示坐标。
设备旋转不得导致相机重建或冻结数据丢失。

### 6.4 辅助功能

- 所有按钮提供中文 VoiceOver 标签和值。
- 颜色风险同时提供文字百分比，不能仅依赖红/绿区分。
- 支持 Dynamic Type；相机叠层中的关键数值至少保持可读。
- 交互命中区域不小于 `44 x 44 pt`。
- “减弱动态效果”开启时，关闭滚轮缩放和非必要过渡动画。

## 7. 状态模型

页面只允许处于以下顶层状态之一：

```text
activationRequired
permissionRequired
startingCamera
live
freezing
frozen
recoverableError
fatalError
```

关键规则：

- `live` 才接收实时测光结果。
- `freezing` 和 `frozen` 锁定同一个基线 `ExposureSnapshot`。
- 每次画幅、焦段或测光配置变化都增加 revision。
- 旧 revision 或旧相机 session 的帧必须丢弃。
- App 进入后台时停止 session；回到前台后恢复为 `live`，不恢复旧冻结帧。

## 8. 隐私与激活

- 只请求相机权限，不请求照片、定位、麦克风和广告跟踪权限。
- 视频帧默认只在内存中处理，不写入照片库或日志。
- 崩溃日志不得记录帧数据、设备激活码或完整设备标识。
- iOS 设备 ID 使用 Keychain 中生成的随机标识，不读取硬件序列号。
- 发布版使用公钥验证签名激活凭证，App 内不得保存可生成激活码的共享密钥。

## 9. 性能目标

| 指标 | 目标 |
| --- | --- |
| 实时 EV 更新 | 8-12 Hz |
| 预览帧率 | 正常设备上不低于 24 fps |
| UI 主线程单帧工作 | 低于 8 ms |
| 风险图长边 | 默认不超过 240 px |
| 冻结到基础蒙层 | 300 ms 内 |
| 含探测帧的完整冻结 | 通常 1.2 s 内 |
| 连续运行 10 分钟 | 无持续内存增长、无相机中断 |

发生热降频时优先降低分析频率，不降低预览稳定性，也不改变算法阈值。

## 10. 验收标准

### 10.1 功能验收

- 三种测光模式、临时点测光和恢复预设工作正常。
- ISO、EC、画幅、焦段和宽容度设置重启后恢复。
- 变焦期间保留稳定结果，稳定后拒绝旧 revision 帧。
- 冻结图与风险图来自同一基线帧。
- 冻结状态调整 EC 能立即重算风险图，不请求新基线帧。
- 权限拒绝、相机被占用和 session 中断均有明确恢复路径。

### 10.2 精度验收

在指定参考光源和灰卡条件下：

- 同一 iPhone 重复测量标准差目标不超过 $0.1 EV$。
- 校准后与参考测光表误差目标不超过 $1/6 EV$。
- 输出曝光组合与目标 EV 的离散档位误差不超过 $1/6 EV$。
- Android 与 iOS 使用相同算法测试向量时结果差异不超过 $0.01 EV$。

跨设备误差必须通过设备型号校准记录评估，不能用单一 iPhone 的结果推断全部
机型。

### 10.3 发布验收

- 单元测试和静态分析通过。
- 至少覆盖一台普通广角 iPhone 和一台多摄 iPhone 真机。
- 完成 10 分钟持续运行、前后台切换、电话/控制中心中断恢复测试。
- App Store 隐私清单、相机用途说明、签名和 TestFlight 安装验证完成。
