## 资料可信度备注

- Kodak FunSaver、Kodak Power Flash、Kodak Sport、Kodak TRI-X Single Use 的 ISO、闪光灯和使用场景信息相对容易确认，但焦距、快门、光圈在不同公开资料中存在差异。
- Fujifilm QuickSnap Flash 400 的焦距、ISO、光圈和闪光距离较明确；快门速度存在美国官方页 1/100s 与国际规格页 1/140s 的地区差异。
- Fujifilm QuickSnap Waterproof 的 ISO、焦距、光圈、快门和防水深度来自富士官方规格页，可信度较高。
- Fujifilm C400 果冻胶卷相机的公开规格集中为 ISO 400、f/11、1/125s 和 1–3m 闪光范围；焦距存在 31mm 与 32mm 两种标法，App 采用 31mm 版本。
- Ilford ILFOCOLOR Rapid Retro 的焦距、ISO、快门、光圈来自官方规格，较可靠；但官方未见闪光有效距离。
- AgfaPhoto LeBox Flash 的焦距、ISO、光圈和是否带闪光灯来自官方商品页；闪光距离多来自公开说明资料。
- Lomography Simple Use 的焦距、快门、光圈来自官方商品页；ISO 和宽容度随预装胶片版本变化。
- Dubblefilm SHOW 严格来说是可重复装卷的一次性风格相机，不是传统封闭式一次性相机，因此 ISO 和底片宽容度由用户装入的胶片决定。

## App 内置值

当公开资料仅给出范围或未披露完整曝光参数时，App 必须选择一个固定值才能计算预演 EV。以下是当前实现使用的明确版本：

| 预设 | App 使用参数 | 参数可信度 |
|---|---|---|
| Kodak FunSaver / Fun Saver | 31mm、ISO 800、1/100s、f/10、闪光 1.2–3.5m | 曝光参数取公开范围中的代表值 |
| Kodak Power Flash | 30mm、ISO 800、1/100s、f/16、闪光 1.2–4.5m | ISO 与闪光距离有官方依据；镜头和快门为公开资料近似 |
| Kodak Sport / Waterproof | 30mm、ISO 800、1/125s、f/10、无闪光灯 | ISO 与无闪光灯有官方依据；镜头和快门为同类机型保守近似 |
| Fujifilm QuickSnap Flash 400 | 32mm、ISO 400、1/100s、f/10、闪光 1–3m | 富士官方美国版规格 |
| Fujifilm QuickSnap Waterproof / Marine | 32mm、ISO 800、1/125s、f/10、无闪光灯 | 富士官方规格 |
| Fujifilm C400 果冻胶卷相机 | 31mm、ISO 400、1/125s、f/11、闪光 1–3m | 多个公开商品与媒体规格交叉确认 |
