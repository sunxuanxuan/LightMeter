# FilmLightMeter 双模式产品方案

## 1. 文档状态

- 版本：V2.0 设计基线
- 适用平台：Android、iOS
- 产品形态：专业测光模式 + 胶片预览模式
- 关联文档：[胶片预览技术方案](film-preview-technical-design.md)
- 现有能力基线：Android 当前实现、iOS 迁移版本

本文定义双模式改造后的产品边界、用户流程、功能范围和验收标准。两端允许遵循
各自平台交互规范，但业务语义、预设参数、算法口径和风险结论必须一致。

## 2. 调整背景

当前 App 的所有功能都围绕“测得场景亮度，再推荐用户应使用的曝光组合”展开，
适合掌握 ISO、光圈、快门和测光方式的胶片摄影用户。

新版本增加面向一次性胶片相机用户的预演能力。用户不需要决定曝光组合，只需
选择相机型号，App 就使用该型号固定的胶片 ISO、光圈和快门，回答：

> 在当前光线下使用这台一次性相机拍摄，照片的明暗分布和细节风险大致如何？

这不是普通滤镜功能。首要目标是解释固定曝光参数在当前场景中的曝光结果，
其次才是提供颗粒、色调等观感近似。

## 3. 产品目标

1. 保留现有专业测光能力，不降低精度和操作效率。
2. 让不了解曝光参数的用户也能判断一次性相机是否适合当前场景。
3. 实时显示固定曝光下的明暗趋势，并明确提示高光和暗部风险。
4. 让预览结果可解释：展示相机参数、场景判断和建议，而不是只显示滤镜画面。
5. Android 与 iOS 对同一测试输入给出一致的曝光偏差和风险结论。

## 4. 非目标

首版不承诺：

- 像素级还原某款胶片、冲洗药水、扫描仪和后期软件的最终色彩。
- 使用手机真实光圈、ISO 和快门直接复刻胶片相机成像。
- 准确模拟塑料镜头的眩光、像差、失焦和个体差异。
- 在缺少主体距离和深度信息时准确模拟闪光灯照明。
- 替代真实胶片的试拍、包围曝光和冲扫验证。
- 保存手机拍摄照片或将本 App 变成胶片相机拍摄 App。

产品文案统一使用“曝光预演”“效果近似”和“风险提示”，不得使用“真实还原”
或“保证成片”等表述。

## 5. 用户与场景

### 5.1 专业模式用户

- 使用胶片相机，需要独立测光表的摄影者。
- 需要点测光、画幅取景、曝光组合和宽容度分析的进阶用户。
- 希望校准设备并控制 ISO、EC、光圈和快门的用户。

### 5.2 胶片预览模式用户

- 第一次使用一次性胶片相机，不理解曝光三要素的用户。
- 在室内、阴天、夜间或逆光场景中，不确定是否能拍到的用户。
- 希望提前判断是否需要闪光灯、靠近主体或更换场景的用户。

### 5.3 典型任务

```text
专业模式：当前场景应该使用什么参数？
预览模式：使用选中的固定参数拍摄，大概会得到什么结果？
```

## 6. 信息架构

激活和相机权限通过后进入模式首页：

```text
FilmLightMeter
├── 专业测光
│   ├── 实时测光
│   ├── 曝光组合
│   ├── 冻结与宽容度风险
│   └── 专业设置
└── 胶片预览
    ├── 一次性相机选择
    ├── 实时曝光预演
    ├── 风险说明
    └── 预设详情
```

首页记住上次使用模式，但设置中必须提供“启动时显示模式选择”开关。首次完成
权限流程后默认显示模式选择，不替用户预设专业程度。

## 7. 专业测光模式

专业模式即现有功能集合，改版只调整入口和共享组件，不改变算法语义：

- 平均、中央重点和点测光。
- 临时点击点测光。
- ISO 与 $1/3 EV$ 步进曝光补偿。
- 光圈、快门主推荐及等效组合。
- 135、APS-C、6x4.5、6x6 画幅与 20-150 mm 候选焦段；实际范围按设备硬件
  能力和当前画幅动态收缩。
- 胶片宽容度预设。
- 冻结帧、明暗探测帧和高光/暗部风险图。
- 测光配置、相机机型测光预设和设备校准。

模式切换不重置专业设置。专业模式的 ISO、EC、画幅、焦段和测光配置继续独立
持久化。

## 8. 胶片预览模式

### 8.1 核心流程

```text
选择一次性相机
  -> 查看固定参数和使用提示
  -> 进入实时曝光预演
  -> 查看场景评级与风险区域
  -> 可冻结画面查看详细解释
  -> 改变相机预设或恢复实时预览
```

### 8.2 相机选择页

每张预设卡片显示：

- 品牌和型号。
- 胶片类型与 ISO。
- 固定光圈、快门和焦距。
- 是否带闪光灯及有效距离。
- 参数依据等级：官方资料、实测资料、经验近似。
- “适合晴天”“室内建议闪光”等简短说明。

支持按品牌、ISO 和闪光灯筛选。首版不提供用户自定义预设，避免未经校验的参数
被误认为官方型号；内部调试构建可以开放 JSON 导入。

### 8.3 实时预演页

页面分为四层：

1. 模拟取景框：按预设焦距和 135 画幅显示视野。
2. 曝光预演画面：根据固定曝光参数映射亮度，不跟随手机自动曝光改变观感。
3. 风险叠层：高光使用红色、暗部使用绿色，并提供非颜色文字说明。
4. 状态面板：显示型号、胶片预设固定曝光、场景推荐曝光、相对差值和操作建议；
   不直接展示“良好”“注意”“较差”等评级标签。

首屏只保留三项主要操作：

- 切换预设。
- 开关风险叠层。
- 冻结/恢复。

ISO、光圈和快门只读展示，不能像专业模式一样调整。否则产品语义会从“这台
相机会拍成什么样”退化为另一个专业测光页面。

### 8.4 场景评级

系统内部根据有效取景框内的风险比例和整体曝光偏差计算四级结论，用于选择
操作建议，但预览模式 UI 不直接展示评级文字：

| 等级 | 含义 | 默认文案 |
| --- | --- | --- |
| 良好 | 主体曝光可用，风险面积低 | 当前光线适合拍摄 |
| 注意 | 存在局部高光或阴影风险 | 可以拍摄，注意标记区域 |
| 较差 | 大面积细节可能丢失 | 成片风险较高，建议调整 |
| 不可判断 | 元数据、画面或设备状态不可靠 | 暂时无法可靠预演 |

评级阈值由跨平台测试向量固定，不使用平台 UI 自行判断。面积只是辅助指标；
中央主体区域的风险应具有更高权重，避免小面积背景天空主导整个结论。
偏暗、偏亮和闪光灯等异常操作建议使用错误红色；适合拍摄和等待测光使用
中性色。

### 8.5 风险说明

实时阶段使用同一帧的逐像素 EV 图进行快速风险判断。冻结后沿用专业模式的
$+2 EV/-2 EV$ 探测帧能力，降低黑头发、黑衣服、白墙等固有颜色导致的误报。

冻结详情显示：

- 高光风险百分比。
- 暗部风险百分比。
- 当前相机固定曝光相对场景测光值的偏差。
- “可能欠曝”“高反差场景”“手机预览已裁切”等原因标签。
- 一条优先级最高的行动建议。

建议示例：

- “环境比该相机适用范围暗约 2 EV，建议开启闪光灯。”
- “主体距离超过闪光灯有效范围，建议靠近至 1-3 m。”
- “背景高光可能丢失，调整拍摄方向可降低反差。”
- “当前场景适合拍摄，保持相机稳定。”

### 8.6 闪光灯

首版将闪光灯分为“使用建议”和“画面模拟”两个能力：

- 必须实现：展示预设有效距离，并根据环境曝光判断是否建议开启。
- 必须实现：用户选择“闪光灯开启”后，明确说明背景仍按环境光曝光。
- 暂不承诺：在整幅实时画面中精确绘制闪光灯后的主体亮度。

原因是闪光曝光依赖主体距离、反射率、遮挡和照射角。没有深度信息时，将整幅
画面统一提亮会产生错误结论。后续版本可增加“主体距离”输入或使用受支持设备
的深度数据，并始终标记为近似模拟。

### 8.7 冻结状态

冻结后锁定以下内容：

- 原始彩色帧。
- 逐像素场景 EV 图。
- 手机曝光元数据。
- 预设 ID 和版本。
- 取景框、时间戳、revision 和 session ID。

用户可以切换风险叠层，但不能在冻结状态切换相机预设。切换预设需要先恢复
实时预览，防止用户把旧帧结果误认为新预设的实时判断。

## 9. 预设体系

### 9.1 参数范围

每个预设至少包含：

| 分类 | 参数 |
| --- | --- |
| 身份 | 稳定 ID、版本、品牌、型号、地区或批次 |
| 曝光 | 胶片 ISO、固定光圈、固定快门 |
| 取景 | 焦距、画幅、最短对焦距离 |
| 胶片 | 类型、高光宽容度、暗部宽容度 |
| 闪光 | 是否支持、有效距离、参数依据 |
| 显示 | 简介、使用建议、可选观感配置 |
| 证据 | 来源等级、来源 URL、校验日期 |

同一型号在不同地区或批次参数不一致时，必须建立不同版本，不能静默覆盖。

### 9.2 首发建议

首发至少提供：

1. Fujifilm QuickSnap Flash 400。
2. Kodak FunSaver 800。
3. 通用 ISO 400 一次性相机，用于无法确认具体型号的用户。

Fujifilm 官方不同地区页面存在 `1/100 s` 与 `1/140 s` 两种快门资料，因此应
按包装地区或批次拆分预设。官方页面提供的共同参数为 ISO 400、32 mm、f/10、
固定焦点和约 1-3 m 闪光范围：

- [Fujifilm QuickSnap UK 产品页](https://my.fujifilm.com/uk/instax/fujifilm-quicksnap-disposable-camera-69178)
- [Fujifilm QuickSnap 官方规格页](https://www.fujifilm.com/al/en/consumer/films/quicksnap/specifications)

Kodak FunSaver 的公开参数来源一致性不足，进入正式预设前必须完成实物测量或
取得可追溯资料。未完成前标记为“实验预设”，不得使用“官方参数”标签。

### 9.3 可信度展示

| 等级 | 定义 | UI 标识 |
| --- | --- | --- |
| A | 厂商当前官方规格或技术资料 | 官方资料 |
| B | 多个独立来源一致或项目实测 | 实测资料 |
| C | 单一来源、推测或同类产品近似 | 经验近似 |

曝光参数与胶片宽容度分别记录证据等级。例如相机光圈可能为 A，胶片曲线仍可能
为 C，不能合并成一个笼统可信度。

## 10. 预览效果分层

为避免“曝光判断”和“风格滤镜”相互污染，渲染分为三层：

1. 曝光层：固定参数决定明暗落点，是风险判断的唯一依据。
2. 胶片响应层：使用趾部、线性区和肩部曲线压缩亮度。
3. 观感层：色彩矩阵、颗粒、暗角和轻微软化，只影响显示。

用户关闭“胶片观感”后，曝光层和风险结论保持不变。颗粒、色偏或暗角不得参与
风险像素统计。

## 11. 设置与持久化

新增持久化项：

- 上次使用模式。
- 是否启动时显示模式选择。
- 上次选择的一次性相机预设 ID 和版本。
- 风险叠层开关。
- 胶片观感开关。
- 闪光灯选择状态。

专业模式与预览模式的设置分开存储。升级已有安装时：

- 默认保留全部专业设置。
- 上次模式默认为专业模式。
- 第一次进入新版本时只展示一次功能引导。

## 12. 权限、隐私与无障碍

- 继续只请求相机权限，不因预览模式请求照片、位置或麦克风权限。
- 所有帧默认只在设备内存中处理，不上传、不保存。
- 风险不能只用红绿颜色表达，必须同时显示文字、图标或纹理。
- 关键按钮命中区域不小于 Android `48 dp` 或 iOS `44 pt`。
- VoiceOver/TalkBack 应朗读场景评级、固定参数和风险比例。
- “减弱动态效果”开启时，关闭颗粒动画和非必要转场。

## 13. 异常与降级

| 场景 | 行为 |
| --- | --- |
| 相机权限缺失 | 显示权限说明，不展示伪造预览 |
| 曝光元数据缺失 | 标记“不可判断”，保留普通相机画面 |
| AE 快速变化 | 暂停提交新结论，保留上一稳定结果 |
| 手机高光已裁切 | 显示保守高光警告，不推断真实超出档数 |
| 预设版本不存在 | 回退预设选择页，不自动替换成其他型号 |
| 设备性能不足 | 降低模拟帧率和分辨率，风险阈值保持不变 |
| 探测帧失败 | 使用基础阈值风险图，并标注“保守估计” |

## 14. 成功指标

首版以质量指标为主，不要求接入远程统计：

- 新用户可以在 30 秒内完成预设选择并理解当前是否适合拍摄。
- 稳定场景下，预览亮度不随手机 AE 呼吸产生明显跳变。
- 同一场景、同一预设重复判断的整体曝光偏差波动不超过 $0.2 EV$。
- 双端共享测试向量的像素风险分类一致率不低于 99.5%。
- 所有风险结论都能追溯到相机参数、场景 EV 和宽容度阈值。

## 15. 发布阶段

### 阶段 1：双模式框架

- 新增模式选择和独立状态持久化。
- 专业模式迁入新导航，行为保持不变。
- 建立预设模型、可信度和参数详情页。

### 阶段 2：曝光预演 MVP

- 实现固定参数曝光偏差计算。
- 实现实时亮度映射、取景框和基础风险叠层。
- 支持冻结、探测帧和详细风险说明。
- 首发至少一个 A 级参数预设和通用预设。

### 阶段 3：观感与校准

- 加入可关闭的胶片响应、颗粒、暗角和色彩配置。
- 使用灰卡、色卡和真实冲扫样片校准。
- 扩充经过验证的一次性相机数据库。

### 阶段 4：闪光近似

- 增加主体距离输入或深度能力检测。
- 计算环境光与闪光的合成曝光。
- 单独验证主体、背景和有效距离提示，不降低无闪光模式可靠性。

## 16. 产品验收

发布前必须满足：

1. 专业模式现有核心功能无回归。
2. 预设固定参数不能在预览页被用户意外修改。
3. 同一帧、同一预设的预演画面与风险图使用同一个曝光快照。
4. 切换预设、切换模式和前后台恢复不会显示旧 revision 结果。
5. 关闭观感层不改变任何风险比例和场景评级。
6. 无法可靠计算时显示“不可判断”，不得输出看似精确的结果。
7. 参数来源和近似边界在预设详情及帮助页面可见。
